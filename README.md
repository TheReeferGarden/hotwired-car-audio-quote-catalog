# Hotwired Car Audio (Brookland AR) quote builder data — NOT The Reefer Garden

This repo holds the **public data files** for the Hotwired Car Audio quote builder (Brookland, Arkansas).
It has nothing to do with The Reefer Garden; it only lives under this GitHub account.

The quote page loads these files through the jsDelivr CDN when its `window.HW_DATA_BASE` switch is set to
`https://cdn.jsdelivr.net/gh/TheReeferGarden/hotwired-car-audio-quote-catalog@main/`. If a file can't be loaded,
the page falls back to the copy hosted on the shop's own site.

Everything here is customer-facing and sanitized: customer prices only (MSRP; Memphis at MAP), no costs, no dealer
prices, no supplier names. The files are generated by the shop's build; don't edit them by hand.

## Folders

| Folder | What's in it |
|---|---|
| `data/vehicles/` | `vehicles.compact.json`: year / make / model list with the dash kits, harnesses and interfaces that fit each vehicle (customer prices). `speaker-size-fitment.json`: factory speaker sizes by vehicle (front / rear / dash / door). |
| `data/catalog/` | `catalog.json`: the parts catalog shown in the quote builder (radios, speakers, subs, amps, accessories), including the Harley parts, boat and powersports / golf cart sections. |
| `data/enclosures/` | `enclosures.slim.json`: subwoofer enclosures (vehicle-specific and universal). |
| `img/kits/` | Dash kit photos for the "What is this?" popup (360x270 JPEG, named by part number). |

## CDN cache

`@main` files are cached by jsDelivr for up to 12 hours. After an update the shop's push script asks jsDelivr to purge the
changed files (`https://purge.jsdelivr.net/gh/TheReeferGarden/hotwired-car-audio-quote-catalog@main/<file>`); jsDelivr
only supports branch purges on a best-effort basis, so allow up to 12 hours in the worst case.
